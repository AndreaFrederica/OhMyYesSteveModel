# Historical v3 dynamic transform vector

`legacy_v3_dynamic_vector.ysm` was generated with the libraries bundled by the
historical `ysm-native` implementation (`city_d.lib` and `chacha_d.lib`) plus
its dirty-Zstandard block-header mapping. It is not generated by the decoder
under test.

- Summary: `x`
- Envelope version: little-endian `3`
- Password byte `i`: `(i * 7 + 3) mod 256`
- Plaintext size: 12,004 bytes
- Envelope size: 12,095 bytes
- SHA-256: `548e5610a57e561f84878882f14dd3557aac1c73c073accc5ee970312d8ac2f3`
- Plaintext version: little-endian `1`
- Plaintext bytes from offset 4: low byte of successive `std::mt19937_64`
  outputs seeded with `0xD15EA5E`
- The ciphertext crosses at least one historical dynamic ChaCha parameter
  boundary.

The historical parameter updater rotates `chacha_state::buffer`, an unused
scratch region at these full-chunk boundaries, and XORs only the 48-byte wire
state with the chunk hash. This fixture freezes that observed writer behavior;
rotating the wire state instead is incompatible with production files.

The generator was also linked against the new decoder before this fixture was
frozen, so the vector covers CityHash, XChaCha initialization, dynamic
parameter mutation, mt19937 XOR, salt removal, dirty block normalization, and
streaming Zstandard decompression as one pipeline.
