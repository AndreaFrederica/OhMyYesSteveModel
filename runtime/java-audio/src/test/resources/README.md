Synthetic 60001-frame mono/stereo sine fixtures generated by `generate.py`,
covered by the repository license. Encoding and reference decoding used
FFmpeg 6.0 (Gyan full build), libopus/libvorbis encoders and FFmpeg decoders.
Stereo output is averaged to mono, not FFmpeg's default equal-power downmix.

Exact frame count and read-size invariance are mandatory. JOrbis is compared
within 2 signed-16-bit LSB. Concentus implements fixed-point Opus 1.1.2 while
the independent FFmpeg reference is floating point: this test requires peak
error <=8 LSB and SNR >=70 dB. Observed peaks are 3 LSB mono and 5 LSB stereo;
this is not a claim of byte-identical PCM with the official native decoder.
The builtin corpus additionally exercises 50 Vorbis and 4 Opus streams,
including a short Opus stream whose first audio page also carries EOS.
