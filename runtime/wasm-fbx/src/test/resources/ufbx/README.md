# Source fixtures

These FBX files and OBJ reference exports are copied without modification from the ufbx revision recorded in `sources.json`. Each file has its original URL and SHA-256. The upstream dual MIT/public-domain license is retained in `LICENSE.txt`.

The OBJ positions are source DCC exports, not output generated by our FBX evaluator. Maya light and pivot reference values come from the same upstream `test_animation.h` and `test_transform.h`. Cases marked `ufbx:transform_skin` in the original OBJ use explicit mesh-node bind-pose compensation, as described by upstream `testing_utils.h`; other cases use world binding. Empty OBJ groups contain no geometry and do not count as model instances.

Position comparisons cover all source corners at the indicated frames. They do not establish image equality, material rendering equality, normal-map correctness, or universal FBX compatibility. A separate regression changes authored FBX normals while keeping geometry/animation fixed and verifies that evaluated normals change rather than being regenerated from topology.
