# 通用网格后端

本方向依据[双后端决定](../product-decisions/decisions/dual-model-backends.md)。当前支持与验证结果见[实施状态](../status/general-mesh-backend.md)，计划不表示能力已经可用。

MC 风格管线保留现有几何、动画与数值动态响应。通用网格建立独立场景资产、节点/skin、morph、约束、动画时间线和物理实例；两者共享资源与宿主服务，不共享可变姿态。

前置负责有界解析、不可变资产、动画采样、CPU 变形、物理接口与可回放时间线；本体负责游戏输入快照、资源发布、UI、网络与图形提交。完整节点层级与 skin joint 集合分离，源格式专属语义由类型化行为描述保留。

Bullet WASM 已在纯 JVM 引擎中接入 MMD 骨骼调度、刚体、关节、软体材质绑定和回放；当前前置结构见[通用网格运行库](../architecture/general-mesh-runtime.md)。特殊锚点和源软件复杂行为仍需补全与差分验收，并验证真实模型和多人并行成本。native 只能成为同一能力的可选加速。

灯光和阴影保留数据与时间线输出，具体效果由扩展承接。正式容器/schema 和网络能力需要独立版本演进，不能改变旧制品语义。完整目标同时要求 CPU/GPU、多视图、预览/游戏、托管/native 的一致性与旧 MC 内容回归。
